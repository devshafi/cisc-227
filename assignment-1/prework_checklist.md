# Assignment 1 Pre-Work Checklist

Complete this **individually**, before your group's role-play session. This is
logistics setup for the whole course, not part of the requirements deliverable —
you will use these tools starting in Assignment 2.

- [ ] Install a code editor (VS Code recommended).
- [ ] Install git and confirm it works: `git --version`.
- [ ] Create a GitHub account (use a real name or one you're comfortable your
      instructor/TA seeing — this is the account you'll use for the whole course).
- [ ] Create the group's GitHub repository (one member creates it, adds the rest
      of the group as collaborators).
- [ ] Invite your assigned TA as a collaborator on the repository.
- [ ] Confirm every group member can clone the repository.

Submit confirmation of the last three items (repo link, collaborator list
screenshot, or equivalent) with your Assignment 1 submission.
